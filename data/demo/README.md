# Demo records

The actual seed is generated by `backend/app/seed.py`, using PRNG seed `24042` and a configurable anchor date. From `backend/`, use the virtual environment's Python to run `python -m alembic upgrade head` and `python -m app.seed`. The seed creates 42 days for five products at two synthetic Astana locations, including weekday/weekend patterns, stock, write-offs, listings and orders. Product names, addresses, customers and all operating records are synthetic.

Set `DEMO_ANCHOR_DATE=2026-10-24` in `backend/.env` to reproduce historical dates exactly; the default is the current local date in `Asia/Qyzylorda`. The anchor cannot be in the future. Current live pickup windows are generated relative to execution time, so the PRNG/history are reproducible while an active marketplace remains demonstrable. Stored records do not roll forward automatically. Active reservations/listings can expire during normal API use.

An existing bakery is not overwritten by `python -m app.seed`. For an explicit reset of the isolated demo database, use `python -m app.seed --reset` with `WORKSPACE_MODE=demo`, or the confirmation flow in Settings. Reset deletes records in that configured database. For Docker Compose, run `docker compose exec backend python -m app.seed` from the repository root after the containers start; supply a custom anchor with `docker compose exec -e DEMO_ANCHOR_DATE=2026-10-24 backend python -m app.seed` if needed.

For a separate empty real-data workspace, set its own `DATABASE_URL` and `WORKSPACE_MODE=real`, migrate it, then run `python -m app.seed --empty`. This creates only a bakery, placeholder location and settings. Do not use the synthetic seed as real operating evidence. Real mode still requires access controls before private business use.

`records-example.csv` illustrates the UTF-8 comma-separated import schema. IDs refer to the seeded catalog. Review dates and stock before importing; imports are validated atomically and never silently repair stock. The example is additional synthetic data, not a complete dataset or a reset procedure.
