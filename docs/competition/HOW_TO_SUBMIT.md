# Как подать заявку: пошагово, чтобы не запутаться

Срок — **сегодня, 22.11, до 23:59 по Астане**. Цель — отправить до 22:00, с запасом.
Подаёт **капитан** команды. Нужен компьютер, хороший интернет и 1–1,5 часа.

## Шаг 0. Подготовьте папку `ITFEST_SaqtaFood` на компьютере
Положите туда всё ниже. Имена файлов — латиницей, без пробелов.

| Файл | Как сделать | Проверка |
|---|---|---|
| `SaqtaFood_pitch.pdf` | Google Slides или Canva → 12 слайдов по тексту из `PITCH_DECK.md` → **Файл → Скачать → PDF** | ≤ 12 слайдов, ≤ 20 МБ, все цифры совпадают с AI-картой |
| `SaqtaFood_AI_card.pdf` | **Готов:** `docs/competition/pdf/` | 2 страницы; пункт 9 правдив |
| `SaqtaFood_Lean_Canvas.pdf` | **Готов:** `docs/competition/pdf/` | 9 блоков + экономика и рынок |
| `SaqtaFood_competitors.pdf` | **Готов:** `docs/competition/pdf/` | 5 конкурентов, есть ссылки |
| Ссылка на видеопитч | YouTube → **Создать → Загрузить видео** → доступ **«Доступ по ссылке»** | ≤ 3:00; ссылка открывается в режиме инкогнито |
| Ссылка на демо-видео | Так же, YouTube «Доступ по ссылке» | ≤ 2:00, без монтажа |
| Справки из школы | Скан или фото каждой справки → PDF | у каждого участника |
| Согласия родителей | Распечатать Приложение 4 из положения, подписать, отсканировать | у каждого несовершеннолетнего |

**Метаданные PDF.** Перед загрузкой откройте PDF → **Файл → Свойства**. В полях «Автор», «Тема», «Ключевые слова»
должно быть только название проекта или пусто. Никакого скрытого текста для ИИ-жюри (п. 12.2 — дисквалификация).

## Шаг 1. Регистрация на сайте фестиваля
1. Откройте **itfest.kz** → регистрация → войдите или создайте аккаунт капитана.
2. Выберите секцию **StartUp Battle**. Сайт перенаправит на **aistartify.com**.

## Шаг 2. Платформа aistartify.com
1. Зарегистрируйтесь (тот же email капитана).
2. Введите промокод для школьников: **ITFEST2026S**.
3. Если что-то непонятно, откройте инструкцию организатора (ссылка в положении, п. 5.1)
   или спросите в Telegram-чате участников: https://t.me/+u1jO4ouBeb1jMGYy

## Шаг 3. Анкета команды
- Название проекта: **SaqtaFood**. Категория: **Школьники**. Город.
- На каждого участника: ФИО, дата рождения, школа, класс, телефон, email, **роль в команде**.

## Шаг 4. Описание проекта (если в форме есть текстовые поля)
Готовые короткие тексты:
- **Проблема:** «Пекарни каждый день решают, сколько печь, "на глаз" или "как вчера". Лишнее уходит в списание,
  а при нехватке пекарня теряет покупателей».
- **Решение:** «SaqtaFood Forecast — ИИ-план выпечки по каждому товару на завтра и неделю, с проверкой точности.
  SaqtaFood Save — продажа остатков покупателям со скидкой с бронированием по коду».
- **Роль ИИ:** «Для каждого товара соревнуются 5 методов, включая ридж-регрессию; побеждает самый точный на прошлых
  днях, а последние 7 дней — честная проверка вслепую. На синтетических данных ошибка WAPE 15,5 % против 21,9 %
  у метода "как вчера". Реальную точность измерим в пилоте».
- **Тяга:** только правда: работающий сайт, анкета от пекарни, план пилота. Не пишите о клиентах, которых нет.
- **Ссылка на продукт:** адрес сайта, который **точно работает** (проверьте в режиме инкогнито прямо перед отправкой).

## Шаг 5. Загрузка и отправка
1. Загрузите PDF-файлы и вставьте ссылки на видео.
2. Отметьте согласия (с положением, на обработку данных).
3. Перед кнопкой **Отправить** откройте каждую ссылку в режиме инкогнито: видео играет, сайт открывается.
4. Отправьте. Сделайте **скриншот** страницы «заявка отправлена» и письма-подтверждения.

## Если что-то сломалось
- Сайт не открывается: подождите минуту (бесплатный сервер просыпается — на сайте появится баннер с прогрессом)
  и обновите страницу.
- Видео не грузится на YouTube: загрузите на Google Drive → **Поделиться → Все, у кого есть ссылка → Читатель**.
- Форма не принимает файл: проверьте размер (≤ 20 МБ) и формат (PDF).
