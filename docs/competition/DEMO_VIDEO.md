# Сценарий демо-видео (до 2:00, запись экрана без монтажа)

Правила: одна непрерывная запись экрана, без склеек и ускорения. Можно говорить голосом поверх записи.
Записывать на **живом сайте**. Бесплатный сервер засыпает: **за 2 минуты до записи** откройте
`https://saqta-api.onrender.com/api/health` и дождитесь ответа `"status":"ok"`.
Запись: Windows — Win+Alt+R (Xbox Game Bar) или OBS; окно браузера 1280×720, масштаб 100–110 %.
Демо-аккаунт пекарни и покупателя создаёт оператор (см. `docs/DEPLOYMENT.md`, раздел «Демо-пекарня»).

| Время | Действие на экране | Что сказать |
|---|---|---|
| 0:00–0:10 | Главная страница SaqtaFood | «Это SaqtaFood. Покажу, как пекарня узнаёт, сколько печь завтра». |
| 0:10–0:20 | «Войти» → вход в демо-пекарню (логин заранее в менеджере паролей или вставить из буфера) | «Я вхожу как владелец демо-пекарни. Данные синтетические, это помечено». |
| 0:20–0:35 | Forecast → видна загруженная история продаж (150 дней) | «История продаж загружена из Excel: пять месяцев, по каждому товару». |
| 0:35–0:50 | Выбрать товар (например, «Круассан классический»), горизонт 7 дней → «Построить прогноз» | «Строю прогноз на неделю вперёд». |
| 0:50–1:15 | Экран результата: план на завтра, пометка «Прогноз сделан ИИ, решение принимает человек», выбранный метод, сравнение 5 методов, MAE/WAPE на последних 7 днях | «Пять методов соревнуются, и для этого товара победила регрессия. Видно её ошибку на последних 7 днях, которые модель не видела, и сравнение с "как вчера"». |
| 1:15–1:30 | Изменить запас (буфер) → план пересчитался | «Решение за пекарем: можно поменять запас, и план обновится». |
| 1:30–1:50 | Save → «Создать предложение»: товар, количество, скидка → опубликовать | «Если к вечеру остаётся излишек, выставляю его в Save со скидкой». |
| 1:50–2:00 | Страница Save глазами покупателя: предложение видно, кнопка бронирования | «Покупатель видит предложение, бронирует и забирает по коду. Так меньше хлеба уходит в мусор». |

Перед записью: прогнать сценарий 2 раза вслух с секундомером; закрыть лишние вкладки и уведомления;
не показывать на экране пароли, email и личные данные.
После записи: загрузить на YouTube с доступом по ссылке, проверить ссылку в режиме инкогнито.
