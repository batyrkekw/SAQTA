# Оператор SaqtaFood

Скрипт `scripts/operator.py` использует только стандартную библиотеку Python и `/api/admin/*`. Запускайте его из корня репозитория при работающем API.

Задайте `API_URL=http://127.0.0.1:8001/api` и `ADMIN_TOKEN` в окружении терминала. Токен должен совпадать с `ADMIN_TOKEN` backend; пустой токен отключает админ-API. Скрипт не читает `.env` автоматически. Для удалённого API разрешён только HTTPS; HTTP допускается для loopback-адресов. Перенаправления запрещены, чтобы не передать токен другому адресу.

Пример для PowerShell 7+: токен вводится скрыто и не попадает в строку команды.

```powershell
$env:API_URL = 'http://127.0.0.1:8001/api'
$env:ADMIN_TOKEN = Read-Host 'ADMIN_TOKEN' -MaskInput
```

Команды (на Linux/macOS используйте `backend/.venv/bin/python`):

```powershell
backend/.venv/Scripts/python.exe scripts/operator.py list-pending
backend/.venv/Scripts/python.exe scripts/operator.py approve owner@example.com business
backend/.venv/Scripts/python.exe scripts/operator.py approve charity@example.com charity
backend/.venv/Scripts/python.exe scripts/operator.py reset-password owner@example.com
```

`list-pending` показывает email, название организации и запрошенную роль. Подтверждайте `business` или `charity` после проверки организации вне приложения. Роль `consumer` снимает доступ бизнеса или благотворительной организации.

`reset-password` дважды запрашивает новый пароль скрытым вводом, принимает 10–128 символов и завершает все существующие сессии этого пользователя. Пароль нельзя передать аргументом или через перенаправленный stdin. Передайте его владельцу по отдельно согласованному каналу: скрипт не отправляет сообщения и не реализует восстановление по email.

Скрипт выводит только результат или безопасное описание ошибки; пароль, токен, тела ошибок API и содержимое заказов не выводятся. Код завершения: `0` — успех, `1` — ошибка, `130` — отмена. При потере связи результат изменения может быть неизвестен: проверьте состояние перед повтором. Не сохраняйте секреты в Git или в командных файлах.

Коды получения видит покупатель. Старые активные заказы без `buyer_id` нужно отменить и забронировать заново из аккаунта покупателя. Операторский скрипт не раскрывает коды продавцу и не обходит проверку получения.

Локальный запуск и настройки лимитера — в [README](../README.md).
